# Change: 新增万年历（calendar）

## Why

`docs/TOOLS_ROADMAP.md`「生活：实用补充」已登记「万年历（类 Apple 日历）」为待开发条目（参考 toolight.cn 等万年历类站点）：公历/农历双显、节假日/节气标注、月视图切换。仓库目前没有任何工具提供农历换算或节气查询能力（`tool-holiday-countdown` 只对少数农历节日做了 2026–2030 的人工对照表，不能把任意一天换算成农历日期）。

## What Changes

新增纯前端工具 `tools/tool-calendar/`，路由 `/calendar`，分类 `utility`：

- **月视图日历**：仿 Apple 日历的月度网格，支持上/下月切换、跳转"今天"，当天高亮。
- **公历/农历双显**：每个日期格子同时显示公历日期数字与对应农历日期（如"初一""廿三"），基于 1900–2100 年农历数据表做真实换算（而非人工对照表，任意日期均可查）。
- **节气标注**：24 节气用近似天文算法（寿星公式，基于回归年长度的年度偏移量）计算，标注在对应格子上；算法精度为 ±1 日，满足日历类工具的展示需求，非天文台级精度。
- **节假日标注**：
  - 固定公历节日（元旦/劳动节/国庆等）与农历传统节日（春节/元宵/清明/端午/七夕/中秋/重阳/除夕等，后者由农历换算实时算出，不依赖人工年份对照表）。
  - **不包含**中国法定节假日的调休安排（放假/调休哪几天由国务院逐年公布，无法算法推导，且每年需要人工更新，超出本次 MVP 范围，仅标传统节日本身）。
- **日期详情**：点击某天展开面板，展示公历日期、农历日期（含干支年可选）、星期、当天的节气/节日（如有）。

技术方案：全部为浏览器本地计算的纯函数，无网络请求、无后端。农历数据表、节气计算常数为静态历法数据（公有领域算法，非受版权保护的创作内容）。

## Capabilities

### New Capabilities
- `calendar`：月视图日历、公历/农历换算、节气标注、节日标注、日期详情面板

### Modified Capabilities
（无）

## Impact

- 新增 `tools/tool-calendar/`（manifest 自动发现，无需手动改 `apps/web/src/config/a-*.ts`）
- 复用 `@toolbox/ui-kit` 的 `PageHero`；可能复用 `DatePicker.tsx` 导出的 `getTodayString`
- 不涉及 `apps/api-gateway` 或任何后端 service
- `docs/TOOLS_ROADMAP.md` 上线后需把该行从「待开发」移到「二、已开发」→ 实用工具
